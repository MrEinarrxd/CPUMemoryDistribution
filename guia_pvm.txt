# GUIA COMPLETA PARA USAR PVM CON CPUMemoryDistribution

Version estable y validada despues de las pruebas realizadas.

## Objetivo

Usar:

* masterOne como nodo maestro.
* slave1 como primer nodo esclavo.
* slave2 como segundo nodo esclavo.

La configuracion utiliza:

* SSH sin contrasena.
* PVM (Parallel Virtual Machine).
* Ejecutable distribuido simSlave.
* Nombres de host fijos: masterOne, slave1 y slave2.
* Ruta comun /tmp/simSlave para evitar problemas por rutas distintas entre usuarios.

> Nota: en los ejemplos se usa damian para slave1 y usuario_slave2 para slave2.
> Cambie usuario_slave2 por el usuario real del segundo equipo, por ejemplo master o rafa.

# REQUISITOS

En los tres equipos:

```
sudo apt update
sudo apt install pvm pvm-dev openssh-server
```

Verificar:

```
which pvm
which pvmd
systemctl status ssh
```

# PASO 1 - IDENTIFICAR LAS IPS

En cada equipo:

```
hostname
hostname -I
```

Ejemplo:

```
masterOne -> 192.168.100.10
slave1    -> 192.168.100.97
slave2    -> 192.168.100.55
```

Anotar las IPs reales.

# PASO 2 - CONFIGURAR /etc/hosts

En los tres equipos:

```
sudo nano /etc/hosts
```

Agregar las IPs reales:

```
192.168.100.10 masterOne
192.168.100.97 slave1
192.168.100.55 slave2
```

Guardar.

Verificar:

```
ping slave1
ping slave2
ping masterOne
```

Si responde correctamente, la resolucion de nombres funciona.

# PASO 3 - CREAR LLAVE SSH EN masterOne

En masterOne:

```
ssh-keygen
```

Presionar Enter en todas las preguntas.

Se generara:

```
~/.ssh/id_rsa
~/.ssh/id_rsa.pub
```

# PASO 4 - COPIAR LLAVES Y CONFIGURAR SSH

Primero copiar la llave publica a cada slave usando el usuario real de cada equipo.

Para slave1:

```
ssh-copy-id damian@slave1
```

Para slave2, cambie usuario_slave2 por el usuario real:

```
ssh-copy-id usuario_slave2@slave2
```

Inmediatamente despues de copiar las llaves, configurar los alias SSH en masterOne:

```
nano ~/.ssh/config
```

Contenido recomendado:

```
Host slave1
    HostName slave1
    User damian

Host slave2
    HostName slave2
    User usuario_slave2
```

Guardar y proteger el archivo:

```
chmod 600 ~/.ssh/config
```

Verificar ahora usando los alias:

```
ssh slave1 hostname
ssh slave2 hostname
```

No debe pedir contrasena. Debe responder con el hostname de cada equipo.

Si falla, probar el acceso largo para distinguir si el problema es la llave o el alias:

```
ssh damian@slave1 hostname
ssh usuario_slave2@slave2 hostname
```

# PASO 5 - CONFIGURAR PVM EN LOS SLAVES

Verificar instalacion:

```
ssh slave1 'find /usr -type d -name pvm3 2>/dev/null | head -1'
ssh slave2 'find /usr -type d -name pvm3 2>/dev/null | head -1'
```

Debe aparecer:

```
/usr/lib/pvm3
```

Configurar variables PVM en cada slave:

```
ssh slave1 'cat > ~/.profile << "EOF"
export PVM_ROOT=/usr/lib/pvm3
export PVM_ARCH=$(/usr/lib/pvm3/lib/pvmgetarch)
export PATH=$PVM_ROOT/lib:$PVM_ROOT/bin/$PVM_ARCH:$PATH
EOF'

ssh slave2 'cat > ~/.profile << "EOF"
export PVM_ROOT=/usr/lib/pvm3
export PVM_ARCH=$(/usr/lib/pvm3/lib/pvmgetarch)
export PATH=$PVM_ROOT/lib:$PVM_ROOT/bin/$PVM_ARCH:$PATH
EOF'
```

Verificar:

```
ssh slave1 'bash -lc "echo $PVM_ROOT"'
ssh slave2 'bash -lc "echo $PVM_ROOT"'
```

Debe mostrar:

```
/usr/lib/pvm3
```

# PASO 6 - COMPILAR EL PROYECTO

En masterOne:

```
cd ~/Documents/GitHub/CPUMemoryDistribution

make clean
make -B
```

Debe generar:

```
./build/CPUMemoryDistributionSimulator
./build/simSlave
```

Verificar:

```
ls -l build/simSlave
ls -l build/CPUMemoryDistributionSimulator
```

# PASO 7 - DISTRIBUIR simSlave

Copiar el ejecutable a una ruta comun en ambos slaves:

```
scp ./build/simSlave slave1:/tmp/simSlave
scp ./build/simSlave slave2:/tmp/simSlave
```

Dar permisos:

```
ssh slave1 'chmod +x /tmp/simSlave'
ssh slave2 'chmod +x /tmp/simSlave'
```

Verificar:

```
ssh slave1 'ls -l /tmp/simSlave'
ssh slave2 'ls -l /tmp/simSlave'
```

Debe aparecer algo similar a:

```
-rwxrwxr-x
```

Importante: /tmp puede limpiarse al reiniciar los equipos. Si aparece "fallo en analisis PVM real" o "simSlave no encontrado", repetir este paso.

# PASO 8 - PROBAR PVM

Iniciar consola PVM en masterOne:

```
pvm
```

Dentro de PVM:

```
add slave1
add slave2
conf
```

Debe mostrar:

```
masterOne
slave1
slave2
```

Salir dejando pvmd activo:

```
quit
```

Si se quiere detener toda la maquina virtual PVM:

```
halt
```

Si algun slave no aparece, verificar:

```
ssh slave1 'bash -lc "echo $PVM_ROOT"'
ssh slave2 'bash -lc "echo $PVM_ROOT"'
ssh slave1 hostname
ssh slave2 hostname
```

# PASO 9 - CONFIGURAR VARIABLES DEL PROYECTO

En masterOne, en la misma terminal donde se ejecutara el simulador:

```
export PVM_RSH=ssh
export PVM_SLAVE_HOSTS=slave1,slave2
export PVM_SLAVE_EXEC=/tmp/simSlave
```

`PVM_SLAVE_EXEC` debe ser una ruta absoluta visible desde los slaves. Para esta guia se usa `/tmp/simSlave`, que tambien es el valor por defecto del programa si no se exporta la variable.

Verificar:

```
echo $PVM_RSH
echo $PVM_SLAVE_HOSTS
echo $PVM_SLAVE_EXEC
```

Debe mostrar:

```
ssh
slave1,slave2
/tmp/simSlave
```

# PASO 10 - PROBAR COMUNICACION PVM DEL PROYECTO

Antes de correr la simulacion completa, probar directamente el master y los dos slaves:

```
./build/CPUMemoryDistributionSimulator
```

Elegir:

```
4. Probar comunicacion PVM
```

La salida esperada debe incluir:

```
=== Prueba PVM real ===
Procesos analizados: 250
Top 5 envejecidos RR
Top 5 desperdicio CPU RR
```

Esta prueba usa un flujo corto: crea slaves, envia datos de prueba, recibe resultados y cierra los slaves.

Si esta prueba falla, revisar primero:

```
ssh slave1 'ls -l /tmp/simSlave'
ssh slave2 'ls -l /tmp/simSlave'
env | grep PVM
pvm
```

Dentro de PVM:

```
conf
```

# PASO 11 - EJECUTAR LA SIMULACION COMPLETA

En masterOne:

```
cd ~/Documents/GitHub/CPUMemoryDistribution
./build/CPUMemoryDistributionSimulator
```

Elegir:

```
1. Simulacion con PVM real
```

En este modo el master crea dos slaves persistentes una sola vez al iniciar la simulacion. Durante la ejecucion envia snapshots cada 5000 iteraciones CPU, integra los resultados y actualiza el dashboard con mensajes como:

```
[PVM REAL] analisis 1
[PVM REAL] analisis 2
```

Al finalizar, el master ejecuta un ultimo analisis distribuido, envia `pvmMessageFinish` a los slaves y cierra su sesion PVM.

Tambien puede ejecutarse sin menu, usando variable de entorno:

```
CPUMEM_PVM_MODE=real ./build/CPUMemoryDistributionSimulator
```

# ERRORES COMUNES

Error:

```
PVM real requiere exportar PVM_SLAVE_HOSTS
```

Solucion:

```
export PVM_SLAVE_HOSTS=slave1,slave2
```

Error:

```
[PVM ERROR] fallo en analisis PVM real
```

Solucion:

```
ssh slave1 'ls -l /tmp/simSlave'
ssh slave2 'ls -l /tmp/simSlave'
scp ./build/simSlave slave1:/tmp/simSlave
scp ./build/simSlave slave2:/tmp/simSlave
ssh slave1 'chmod +x /tmp/simSlave'
ssh slave2 'chmod +x /tmp/simSlave'
```

Error:

```
no se pudieron lanzar todos los hosts configurados
```

Solucion:

```
verificar SSH
verificar /tmp/simSlave
verificar permisos
verificar PVM_SLAVE_HOSTS
```

Error:

```
The value of the $PVM_ROOT environment variable is invalid
```

Solucion:

```
configurar ~/.profile correctamente
verificar:

    ssh slaveX 'bash -lc "echo $PVM_ROOT"'
```

Error:

```
/lib/pvmgetarch: No existe el archivo o el directorio
```

Solucion:

```
ssh slaveX "sed -i '/^export PVM_ROOT=/d' .profile"
ssh slaveX "sed -i '/^export PVM_ARCH=/d' .profile"
ssh slaveX "sed -i '/PVM_ROOT\/lib/d' .profile"
ssh slaveX "printf 'export PVM_ROOT=/usr/lib/pvm3\nexport PVM_ARCH=\$(/usr/lib/pvm3/lib/pvmgetarch)\nexport PATH=\$PVM_ROOT/lib:\$PVM_ROOT/bin/\$PVM_ARCH:\$PATH\n' >> ~/.profile"
ssh slaveX 'bash -lc "echo $PVM_ROOT && echo $PVM_ARCH"'
```

Error:

```
Permission denied
```

Solucion:

```
repetir:

    ssh-copy-id usuario@host
```

Error:

```
simSlave no encontrado
```

Solucion:

```
scp ./build/simSlave slave1:/tmp/simSlave
scp ./build/simSlave slave2:/tmp/simSlave
ssh slave1 'chmod +x /tmp/simSlave'
ssh slave2 'chmod +x /tmp/simSlave'
```

Error:

```
Segmentation fault
```

Solucion:

```
revisar logs del simulador
recompilar con:

    make clean
    make -B
```

# SCRIPT RAPIDO DE DESPLIEGUE

Guardar como:

```
deploy.sh
```

Contenido:

```
#!/bin/bash

set -e

make -B

scp ./build/simSlave slave1:/tmp/simSlave
scp ./build/simSlave slave2:/tmp/simSlave

ssh slave1 'chmod +x /tmp/simSlave'
ssh slave2 'chmod +x /tmp/simSlave'

export PVM_RSH=ssh
export PVM_SLAVE_HOSTS=slave1,slave2
export PVM_SLAVE_EXEC=/tmp/simSlave

./build/CPUMemoryDistributionSimulator
```

Dar permisos:

```
chmod +x deploy.sh
```

Ejecutar:

```
./deploy.sh
```

# CONFIGURACION FINAL CORRECTA

Siempre usar estas variables en la terminal donde se corre el simulador:

```
export PVM_RSH=ssh
export PVM_SLAVE_HOSTS=slave1,slave2
export PVM_SLAVE_EXEC=/tmp/simSlave
```

Antes de ejecutar, confirmar que el slave existe en ambos equipos:

```
ssh slave1 'ls -l /tmp/simSlave'
ssh slave2 'ls -l /tmp/simSlave'
```
