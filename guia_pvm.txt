GUIA PARA USAR PVM CON ESTE PROYECTO
====================================
ssh slave2 'cat > ~/pvm_env.sh << "EOF"
export PVM_ROOT=/usr/lib/pvm3
export PVM_ARCH=$(/usr/lib/pvm3/lib/pvmgetarch)
export PATH=/usr/lib/pvm3/lib:/usr/lib/pvm3/bin/$PVM_ARCH:$PATH
exec "$@"
EOF
chmod +x ~/pvm_env.sh'
Objetivo
--------
Usar este PC como master y dos laptops como slaves, aunque los usuarios sean
distintos:

- Este PC: usuario master, ejecuta CPUMemoryDistributionSimulator.
- slave1: laptop con usuario damian.
- slave2: laptop con usuario master.

La opcion recomendada es configurar aliases SSH en el master y poner simSlave
en el PATH de cada laptop.


1. Crear llave SSH en el master
-------------------------------
En este PC master:

    ssh-keygen

Puedes presionar Enter en todo si no quieres una clave para la llave.


2. Copiar la llave a cada laptop
--------------------------------
Cambia las IP por las IP reales de tus laptops:

    ssh-copy-id damian@IP_LAPTOP_DAMIAN
    ssh-copy-id master@IP_SLAVE2

Prueba que el acceso no pida contrasena:

    ssh damian@IP_LAPTOP_DAMIAN hostname
    ssh master@IP_SLAVE2 hostname


3. Crear aliases SSH en el master
---------------------------------
En este PC:

    nano ~/.ssh/config

Agrega:

    Host slave1
        HostName IP_LAPTOP_DAMIAN
        User damian

    Host slave2
        HostName IP_SLAVE2
        User master

Guarda y prueba:

    ssh slave1 hostname
    ssh slave2 hostname


4. Compilar el proyecto en el master
------------------------------------
En este PC:

    cd /home/master/Documents/GitHub/CPUMemoryDistribution
    make -B

Debe generar:

    ./CPUMemoryDistributionSimulator
    ./simSlave

No uses un comando manual tipo gcc $(find src -name '*.c'), porque puede
incluir archivos viejos o auxiliares como src/presentation/menu.c. El Makefile
ya contiene la lista correcta de fuentes para el master y para simSlave.


5. Copiar simSlave a las laptops
--------------------------------
En cada laptop usaremos ~/bin/simSlave.

Desde el master:

    ssh slave1 "mkdir -p ~/bin"
    scp ./simSlave slave1:~/bin/simSlave
    ssh slave1 "chmod +x ~/bin/simSlave"

Para la segunda laptop:

    ssh slave2 "mkdir -p ~/bin"
    scp ./simSlave slave2:~/bin/simSlave
    ssh slave2 "chmod +x ~/bin/simSlave"


6. Asegurar que ~/bin esta en PATH
----------------------------------
Desde el master:

    ssh slave1 'echo $PATH'
    ssh slave2 'echo $PATH'

Si no aparece /home/damian/bin o /home/master/bin, agrega esto:

    ssh slave1 'echo "export PATH=\$HOME/bin:\$PATH" >> ~/.bashrc'
    ssh slave2 'echo "export PATH=\$HOME/bin:\$PATH" >> ~/.bashrc'

Prueba:

    ssh slave1 "which simSlave"
    ssh slave2 "which simSlave"

Debe responder algo parecido a:

    /home/damian/bin/simSlave
    /home/master/bin/simSlave


7. Instalar e iniciar PVM
-------------------------
En los tres equipos debe estar instalado PVM.

En Ubuntu/Debian:

    sudo apt install pvm pvm-dev

En el master:

    export PVM_RSH=ssh
    pvm

Dentro de la consola de PVM:

    add slave1
    add slave2
    conf
    quit

El comando conf debe mostrar el master y las dos laptops.


8. Ejecutar el simulador con PVM real
-------------------------------------
En el master:

    cd /home/master/Documents/GitHub/CPUMemoryDistribution

    export PVM_RSH=ssh
    export PVM_SLAVE_HOSTS=slave1,slave2
    export PVM_SLAVE_EXEC=simSlave

    ./CPUMemoryDistributionSimulator

Elige:

    1. Simulacion completa con PVM real


9. Verificacion rapida si algo falla
------------------------------------
Ejecuta estas pruebas desde el master:

    ssh slave1 hostname
    ssh slave2 hostname
    ssh slave1 "which simSlave"
    ssh slave2 "which simSlave"

Luego:

    pvm

Dentro de PVM:

    conf

Para apagar PVM:

    halt


Errores comunes
---------------
- "falta export PVM_SLAVE_HOSTS":
  No exportaste PVM_SLAVE_HOSTS en el master.

- "pvmd no esta corriendo":
  No iniciaste PVM con el comando pvm.

- "pvm_spawn fallo":
  PVM no encuentra simSlave, el archivo no tiene permisos de ejecucion,
  el host no esta agregado con add, o SSH no entra sin contrasena.

- "Permission denied":
  Revisa ssh-copy-id y permisos de ~/bin/simSlave.


Resumen para este caso
----------------------
Usa estos valores en el master:

    export PVM_RSH=ssh
    export PVM_SLAVE_HOSTS=slave1,slave2
    export PVM_SLAVE_EXEC=simSlave
